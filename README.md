# Product Page Conversion

A Codex skill for creating, rewriting, and auditing conversion-focused product detail pages (PDPs) for DTC and ecommerce stores.

It helps turn product information into a persuasive page that answers a buyer's essential questions: what the product is, which problem it solves, why it is worth choosing, how it works in real life, and what happens after purchase.

## What it covers

- Outcome-led hero and buy box
- Problem-to-solution messaging
- Feature-to-benefit-to-result copy
- Image and visual-proof briefs
- Product facts, use instructions, and FAQs
- Authentic customer proof
- Shipping, returns, and purchase reassurance
- A prioritized PDP audit format

## Install

Copy this repository into your Codex skills directory:

```powershell
Copy-Item -Recurse . "$env:USERPROFILE\.codex\skills\product-page-conversion"
```

Restart or refresh Codex if the skill is not immediately listed. Then invoke it as `$product-page-conversion`, or let Codex select it for relevant PDP work.

## Important principle

Use only supportable product claims, policies, delivery information, ratings, and reviews. Missing evidence should be identified as a gap or handled with an explicit placeholder, never invented.
